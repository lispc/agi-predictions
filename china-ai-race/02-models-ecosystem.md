# 中国 AI 竞赛专题 2：模型与生态（2026-08-27）

研究日期：2026-08-27。与 lesswrong-ai-futurism/beyond-lesswrong.md 第八节衔接（该节为中国视角简述，本篇展开谱系、数据与一手观点）。

## 一、DeepSeek 谱系：效率路线的技术论证

- **V3**（2024-12）：MLA（多头潜在注意力）+ MoE（细粒度专家+共享专家隔离），官方口径训练成本约 557.6 万美元（2048 卡 H800、预训练阶段），是"效率 scaling"反命题的起点；V2 的 API 定价曾引发中国大模型价格战。论文：[arXiv 2412.19437](https://arxiv.org/abs/2412.19437)
- **R1**（2025-01）：纯 RL（GRPO）驱动推理能力涌现，R1-Zero 证明推理可不经 SFT 冷启动直接从 RL 获得；开源权重 + MIT 协议；MIT 复现成本约 30 美元（s1 论文口径）引爆"低成本推理"叙事；2025-01-27 引发 Nvidia 史诗级抛售（见 ai-finance-bubble/research-05）。
- **NSA**（2025-02，arXiv 2502.11089）：原生可训练的稀疏注意力，64k 长文本训练加速——为 V4 的长上下文铺路，硬件对齐（面向国产芯片优化）是明示目标。
- **V4**（2026-02 旗舰，2026-04-24 Preview/Flash）：总参数约 1–1.6T MoE（腾讯云技术解析称 1.6T、每 token 仅激活约 49B/3%；另有 1T 口径，**官方技术报告未完全确认，冲突并列**）；注意力采用 **CSA（压缩稀疏）+HCA（高度压缩）混合方案**，是 NSA/DSA 谱系的演进，实现原生 1M token 上下文；推理效率提升 3.7 倍、KV Cache 内存仅前代 10%；原生多模态（文本/图像/视频统一）。[DeepSeek 官方 API 文档](https://api-docs.deepseek.com/news/news260424)；[腾讯云技术解析， 2026](https://cloud.tencent.com/developer/article/2661839)；[arXiv 2606.19348](https://arxiv.org/html/2606.19348v1)
- **成本与定价**（官方口径）：V4-Flash 输入/输出约 $0.14–0.28/百万 token，V4-Pro 输入约 $1.74/百万 token；引入**高峰/空闲分时定价**（空闲半价）。训练成本估计约 1000 万美元级（自媒体口径，无法独立验证）。观察者网：V4-Pro 当前价格受高端算力产能限制属"过渡价"，**昇腾 950 下半年量产后将进一步降价**。[观察者网， 2026-04-24](https://www.guancha.cn/economy/2026/04_24_814819.shtml)
- V4 首日同步支持 Nvidia H200 与华为昇腾 950（"零日适配"）——两条腿走路的公开信号（见 research-05 第五节，原始信源可信度偏低但与官方算力合作方向一致）。
- 用量佐证：全球大模型 Token 消耗周榜，DeepSeek V4 Flash 以 3.11 万亿/周居首、腾讯混元 Hy3 3.03 万亿居次。[财经号转述， 2026（中等可信度）](http://mp.cnfol.com/57825/article/1780728846-142473601.html)

**效率路线的论证链**（每一步都有论文级证据）：

1. 预训练 scaling 边际收益递减（固定性能所需算力约 8 个月减半——Epoch 口径 ~3 倍/年的算法进步）；
2. 推理时计算（test-time compute）成为新性能来源（R1 证明）；
3. 中国算力约束（H800→H20→全面断供）→ 把每一 FLOP 的产出最大化成为生存问题而非选择；
4. 结果：算力受限方被迫成为算法效率领跑者——**管制的外部性是把自己的对手逼成了效率专家**。

英文世界对此的反驳（Jeffrey Emanuel 式"算法创新会被算法创新抵消"论）认为效率增益双方共享、算力优势长期仍决定前沿；此争论尚无裁决，但 2025–2026 的基准收敛暂时偏向中国一侧的事实。

## 二、梁文锋一手观点（暗涌访谈，2024-07，36kr/暗涌发布）

## 五、格局判断：中国开源 vs 美国闭源

- 事实层：权重开源的前沿能力主要由中国团队承载（Qwen/DeepSeek 系），美国头部实验室（OpenAI/Anthropic）转向闭源 API，Meta 的 Llama 开源地位被 Qwen 实质接管。Stanford AI Index 2026：顶级闭源模型仅领先顶级开源模型 **3.3%**。[Stanford HAI, 2026-04](https://hai.stanford.edu/ai-index/2026-ai-index-report)
- 机制层：开源对中国是**战略而非商业模式**——渗透率目标（见 03 篇"AI+"意见）+ 生态标准卡位 + 地缘合规护城河。梁文锋"文化行为而非商业行为"是诚实的表述。
- 全球南方维度：开源权重使任何国家可自托管前沿级模型，Qwen/DeepSeek 在监管自主性敏感的市场（东南亚、中东）形成对闭源 API 的结构性替代——这是英文"AI 外交"讨论中经常缺席的一条线。
- 风险层：开源模式把利润率让渡给应用层与云层，模型公司自身商业化薄弱（智谱/MiniMax 上市后仍亏损，"智谱狂飙、MiniMax 失速"的分化已现）；若美国实验室在 agent/多模态拉开代差，开源差距会重新走阔（Kevin Xu 认为 2026 年某些维度差距在扩大而非缩小，[Interconnected, 2026](https://interconnect.substack.com/p/the-us-china-ai-gap-widens-in-2026)，观点类来源）。

| 虎嗅 | 场景分裂论 | "不再全面落后一代，也没全面追平" [虎嗅， 2026](https://www.huxiu.com/article/4865177.html) |

**注意**：基准分差距小 ≠ 前沿研究差距小。三层数据要用三个镜头看：

- 基准分（2.7%）：天花板效应压缩了差距显示度，饱和基准上 2.7% 可能对应能力上的"代差消失"，也可能只是"都考到顶了"；
- Elo 偏好：头部仍被美国实验室占据（Anthropic 1503 vs 阿里紧随其后），"非正式日常使用"中差距大于基准显示；
- 前沿训练算力：差一个数量级（见 01 篇），意味着"下一个范式"（agent、世界模型、长时程任务）的探索速度仍由美国主导。

合理综合：**能力差距以月计（0–9 个月），前沿探索差距以代计**。

## 七、小结与不确定性

1. 中国模型的竞争力结构 = 效率算法（被管制逼出来的）+ 开源生态（41% 下载份额）+ 应用渗透（豆包 180 万亿 token/日）。三者都偏"扩散侧"，而非"起源侧"。
2. 梁文锋访谈是理解中国路线的最好一手文本：AGI 为目标、开源为文化、约束是芯片而非钱——与英文世界"中国只会模仿"的预设直接矛盾。他对"真实 gap 是原创和模仿之差"的自我批评，比任何外部评估都更值得引用。
3. 商业化是短板：开源模式把利润让渡给应用层与云层，模型公司自身造血弱（智谱/MiniMax 上市后仍亏损）；DeepSeek 靠幻方量化输血的模式不可复制，也构成其"不融资"话语的独特性——它不是市场里的公司，是市场里的变量。
4. 不确定性：V4 参数/成本细节未经论文级一手确认；六小龙商业化可持续性；基准收敛是否会在 agent/长任务维度被重新拉开（METR 式口径的中国对应研究缺位）；Qwen 下载量与"真实使用"之间的转化率无公开数据。
