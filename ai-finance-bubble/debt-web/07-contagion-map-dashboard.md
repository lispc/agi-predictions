## 一、传染路径图：以"CoreWeave 类 neocloud 违约"为震中的五环传导

震中设定：某头部 neocloud（CoreWeave 类：总债务 ~$25B、2026 预期 FCF 约 -$18.8B [中]，research-01 §2）发生重组/违约。选择它作震中是因为它是主报告回避清单中**杠杆 × 抵押品贬值 × 循环交易敞口**三重叠加的节点，且其债权人结构横跨私募信贷、银团与公开市场——传导面最宽。

```
震中：neocloud 违约/重组（GPU 抵押品贬值 × 负 FCF × 到期墙，02 篇）
│
├─ 第 1 环【直接债权人】时滞：日–周
│   ├─ GPU 抵押私募信贷（2024-05 $7.5B 银团式 DDTL，Blackstone/Magnetar 牵头 [中]）
│   ├─ 多层 DDTL + 优先债 + 可转债持有人（公开债即时重定价）
│   └─ 银团贷款行（费率与拨备上调）
│
├─ 第 2 环【抵押品与关联主体】时滞：周–月
│   ├─ 全体 GPU 抵押贷 LTV 重估（05 篇：同一抵押品池价格重估，不因单个借款人隔离）
│   ├─ NVDA $6.3B 容量兜底义务显性化（须购买至 2032-04 未售容量 [中]，research-01 §3）
│   └─ 二手 GPU / 时租价格崩（当前 H100 $1.33–2.00/卡时 [中]；抵押物价格反身性）
│
├─ 第 3 环【相关债务人】时滞：月–季
│   ├─ Oracle：RPO $664B 中 ~$300B 归属 OpenAI，单一客户质疑 → 股债双杀（主报告 §四 Phase 1）
│   ├─ 其他 neocloud（Nebius/Lambda/Crusoe 类）再融资窗口关闭（02 篇到期墙前移）
│   └─ 数据中心 ABS/CMBS 利差走阔（Meta Hyperion 类 SPV 融资被连坐重估）
│
├─ 第 4 环【最终持有人】时滞：季–半年（04 篇通道）
│   ├─ 保险一般账户（私募信贷/数据中心债的终端买家，资本规则触发被动减持）
│   ├─ 散户 BDC/非交易 REIT（赎回闸门 gate，06 篇估值纪律：NAV 滞后重估的二段冲击）
│   └─ 银行 fund finance / subscription line 敞口（对私募信贷基金的授信收缩）
│
└─ 第 5 环【宏观】时滞：季
    ├─ AI 债 $1.2T 已成 IG 最大板块 [中] → IG 指数整体重定价，非 AI 发行人连坐
    ├─ 财政部 crowding out 加剧（AI 债供给 $230B+/年叠加 FY2026 赤字 ~$1.9–2T）
    └─ Fed 政策约束：CPI 3.4% 下放水慢于 2020/2023（主报告 §2.6）；Warsh 鹰派周期中
```

各环的放大器与阻断器：

| 环 | 传导时滞 | 放大器 | 阻断器 |
|---|---|---|---|
| 1 直接债权人 | 日–周 | 交叉违约条款；DDTL 未提款额度冻结使其他借款人同步失血（02 篇） | 私募信贷资本锁定 5-10 年、无日频赎回——损失被"存起来"而非强平（06 篇，但也因此传导转为第 4 环的滞后爆发） |
| 2 抵押品/关联主体 | 周–月 | GPU 迭代折损（Goldman：寿命 5→3 年假设使累计折旧摆动 $1T [中]）；拍卖价反身性——违约处置抛售压价 → 其他贷款 LTV 再恶化 | NVDA 兜底接盘未售容量；电力与土地资产残值独立于 GPU（空置率 ~1-2%、北弗吉尼亚 0.3% [中]） |
| 3 相关债务人 | 月–季 | 评级下调触发利差跳档；Oracle 到期墙（FY2027 拟再融 ~$40B 债+股 [中]）撞上再融资关闭 | hyperscaler 接管合同（算力需求本身真实）；Oracle 云收入 +121% 的经营现金流缓冲 |
| 4 最终持有人 | 季–半年 | 散户 BDC 赎回闸门突破 → 被迫卖流动性最好的资产（crash-dynamics/03 §2.2：优质资产先被抛）；保险 RBC 资本规则机械减持 | 保险负债久期长、无挤兑机制；BDC gate 条款本身减速出清（但制造 NAV 失真，类 2015 停牌） |
| 5 宏观 | 季 | 被动指数化（赎回按权重无差别执行）；保证金债务 $1.53T 的日频强平链 | Fed 工具箱终级（2020-03-23 PMCCF/SMCCF 当日见底先例）；财政部回购（当前 $6B/次规模下已证伪，需量级升级） |

**路径图的使用规则**：环 1-2 是"震感"（价格信号，仪表盘高频指标覆盖）；环 3 是"结构损伤"（融资功能丧失，确认信号）；环 4-5 是"系统性事件"（对应主报告尾部情景 -35%+）。**若环 1-2 亮起而环 3 未动，大概率是孤立信用事件（First Brands/Tricolor 式）；环 3 亮起才是情景 A 的信用确认。**

## 二、死亡次序预测表：压力情景下谁先出问题

结合主报告受害顺序（§6.4 回避清单的镜像）与 02 篇到期墙，按"杠杆 × 久期错配"排序（crash-dynamics/03 §2.1 的一般规律：强平顺序与资产质量无关）：

| 序 | 主体类型 | 先行指标（仪表盘对应行） | 预计时滞（从触发事件起） | crash-dynamics 历史案例 |
|---|---|---|---|---|
| 1 | 负 FCF neocloud（CoreWeave 类） | 其公开债价格 <90、GPU 时租环比 -20%（行 4、11） | 0–3 个月（震中本身） | 2001 Global Crossing/WorldCom（烧钱运营商先死，01 篇）；2015 场外配资盘（杠杆最高者先爆，03 篇 §2.1） |
| 2 | GPU 抵押私募信贷基金 / BDC | NAV 折价 >10%、赎回 gate 公告（行 5、12） | 1–2 个季度（自估 NAV 滞后 → 二段冲击） | 2007-06 两只 Bear Stearns 次贷基金（02 篇）；2020-03 BDC 折价 >40%（03 篇 §2.2） |
| 3 | 其他 neocloud / 二线数据中心发行人 | 新发行撤销、ABS 利差 >+150bp（行 6、7） | 1–2 个季度（到期墙前移，02 篇） | 2001 光纤建设商再融资冻结（01 篇）；2022-09 英国养老金后 LBO 一级市场冻结 |
| 4 | Oracle | CDS >150bp、RPO 质量被公开质疑（行 3） | 1–3 个季度 | 2000-01 Lucent/Nortel：vendor financing 反噬设备商（01 篇）；RPO 单一客户 ≈ 2000 年设备商对破产运营商的应收 |
| 5 | 数据中心 ABS/CMBS 及 SPV 债务（Hyperion 类） | 利差 >+300bp、锚定投资者退出（行 6） | 2–4 个季度 | 2007-08 CMBS/ABX 崩盘（02 篇） |
| 6 | NVDA | $6.3B 兜底被实际调用、指引首次显著减速（行 11 为远端信号） | 3–6 个月（盈利真实 → 死于估值与或有负债，而非现金流） | 2001 思科库存减记（盈利真实但为下游烧钱埋单，01 篇） |
| 7 | 表外 SPV 背后的 hyperscaler（Meta/Google 类） | 表外承诺显性化、被迫并表 | 4–8 个季度（最后倒下，有经营现金流兜底） | 2001 安然 SPE 并表（会计信任危机，01 篇）——注意：本轮 hyperscaler 盈利真实，类比仅限"表外结构显性化"机制 |
| 8 | IG 整体 / 保险一般账户 | IG OAS >150bp、保险减持公告（行 2、12） | 半年以上（最慢的强制卖方） | 2008 AIG（保险一般账户成为最后接棒者，02 篇） |

**解读纪律**：次序 1-2 几乎必然先出现且不足以推翻牛市（孤立信用事件已发生：First Brands/Tricolor）；**次序 3-4 的亮起才是"传导成立"的判决点**；次序 5 以后对应主报告尾部情景。NVDA 排第 6 而非第 1，正是主报告"做空对象是循环融资暴露度高的标的、而非 NVDA 本身"（§6.1）的原因。

## 五、如果你是基金经理：灯色对应的动作清单

以下为主报告 §6 与 crash-dynamics/03 §5/§6 的操作化，非个性化投资建议。

**全绿 / 仅利率侧红灯（当前状态）——基准防御姿态：**
- 降低 AI 综合体 beta 而非清仓：市值加权转等权标普是低成本"做空集中度"工具（主报告 §6.1）。
- HY 信用在 OAS 2.65% 无任何补偿意义——**做空/回避**，而非持有吃票息。
- 波动率买方窗口：11 月（中选+FOMC）、2027-01~02（2027 capex 指引，全周期最重要单一事件）。
- 尾部对冲用看跌期权价差（不裸空）；做空对象限循环融资暴露度高的标的——Oracle、neocloud 债、数据中心私募信贷载体——**不做空 NVDA 本身**（盈利真实 + melt-up 轧空风险）。

**黄灯（任一信用侧黄灯亮起，尤其行 1 >3.0%、行 3、行 4、行 7）：**
- 减仓次序按死亡次序表倒序执行：先减 neocloud 债/GPU 抵押 BDC → 再减数据中心 ABS → 再减 Oracle 股债。

- 检查组合里所有"私募信贷 NAV"敞口——按 06 篇纪律，把自估 NAV 当作最多滞后两个季度的价格，用公开市场可比（行 5 折价）折算真实价值。

**红灯组合亮起（红灯 ≥3 且含 HY OAS >4%）——对冲与生存模式：**

**绝不能做（crash-dynamics/03 §6 避免清单 + 本轮两条增量）：**
1. 不接第一刀——第一层下跌里没有任何信息能区分 -10% 回调与 -50% 崩盘；
2. 不带杠杆抄底、不在保证金边上摊平——你的杠杆是别人的强平弹药；
3. 不迷信熔断/跌停的保护——交易限制只改变出清形态，不改变出清；

5. 不以为 Fed put 即时生效——2020 年降息至零+QE 后市场照跌一周再跌 12%，且本轮 CPI 3.4% + Warsh 鹰派意味着"第一针吗啡"来得更慢；
